# Verificação das poses do Ent

O modelo usa somente `IEntAnciaoAnimated`: `SLAM` 52 ticks (preparação até 18, descida de 18 a 22 e recuperação até 52), `ROAR` 60 e `SPIN` 80. O giro visual termina três voltas aos 72 ticks; a última pose visual coincide com a primeira. Fúria altera a respiração sem trocar a fase do ciclo. O modelo não dita nem causa dano: a entidade precisa manter esses tempos para alinhar os efeitos visuais e seus ataques. Latência e atualização dos dados sincronizados podem afetar a precisão entre cliente e servidor.

`EntModelAnimationCheck.java` testa poses usando as classes reais MCP/Forge 1.12.2 no classpath, sem criar uma janela OpenGL. Compile junto com o modelo e a interface usando Java 8, Forge/Minecraft em nomes MCP, LWJGL 2, Guava e as classes do mod; execute `EntModelAnimationCheck`. Verifica continuidade amostrada, início/fim, fases do golpe, chamadas repetidas e limpeza de poses entre entidades, nos dois estados de fúria. Não verifica a aparência, colisões, luz, invisibilidade ou restauração do estado OpenGL em jogo. É necessário testar visualmente no cliente e em multiplayer/dedicado. A geometria original não tem cotovelos, dedos articulados ou mandíbula móvel: a animação usa apenas peças existentes e não garante contato exato dos punhos com o chão. Não há partículas nem sons novos nesta alteração.
